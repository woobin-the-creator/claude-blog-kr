MCP 2026-07-28을 Claude에 도입하다

2026년 7월 28일 · 카테고리: 제품 발표(Product announcements) · 제품: Claude 앱, Claude 플랫폼 · 읽는 데 5분 원문: Bringing MCP 2026-07-28 to Claude (한글 번역본)

모델 컨텍스트 프로토콜(Model Context Protocol, MCP)의 다섯 번째 스펙 릴리스인 MCP 2026-07-28이 오늘 공개됐다. 이번 스펙은 MCP를 상태 없는(stateless) 코어로 옮기고, 인가(authorization)를 한층 견고하게 다듬었으며, 공식 확장(extension)들을 정식 단계로 승격시켰다. 관련 지원은 Claude 제품 전반에 걸쳐 순차적으로 적용되고 있다.

MCP에 새로 들어온 것들

MCP는 최근 월간 SDK 다운로드 4억 건을 넘어섰다. 올해 들어 4배로 늘어난 수치이며, AI 에이전트를 애플리케이션에 연결하는 업계 표준으로 자리 잡았다. MCP 2026-07-28은 지금까지의 스펙 릴리스 가운데 가장 큰 변화를 담은 축에 속한다.

상태 없는 코어(Stateless core). MCP가 양방향 상태 유지(stateful) 프로토콜에서 요청/응답 모델로 바뀐다. 이제 서버를 서버리스와 엣지 인프라에 배포할 수 있다. 덕분에 Claude용 MCP 서버를 만드는 경험이 단순해지고, 서버 채택이 늘어날 때 사용량을 확장하기도 쉬워진다.

표준화된 확장(Standardized extensions). MCP Apps와 Tasks가 버전이 관리되는 확장 프레임워크 아래로 들어왔다. 개발자는 핵심 프로토콜을 건드리지 않고도 인터랙티브 UI나 장시간 실행 작업 같은 기능을 정식 경로를 통해 추가할 수 있다.

인증·인가 강화(Auth hardening). 인가 방식이 실제 프로덕션에서 쓰이는 OAuth 2.0 및 OIDC 배포와 정렬됐다. 따라서 MCP 서버를 Entra나 Okta 같은 엔터프라이즈 아이덴티티 시스템에 우회 처리 없이 연결할 수 있다.

베타 단계부터 생태계 전반의 여러 기업이 MCP 커뮤니티와 함께 이 새 스펙 위에서 개발을 진행해 왔다.

새 스펙에 대한 자세한 내용은 MCP 2026-07-28 릴리스 발표를 참고하면 된다.

Claude 안에서 MCP를 발전시키기

현재 Claude의 커넥터 디렉터리에는 950개가 넘는 MCP 서버가 등록되어 있고, 매일 수백만 명이 이를 사용한다. 올해 Anthropic은 새로운 프로토콜 확장에 대한 지원과 더불어, MCP를 기반으로 개발하고 배포하기 쉽게 만드는 기능들을 함께 출시했다.

MCP Apps는 서버가 대화창 안에 인터랙티브 UI를 직접 렌더링할 수 있게 한다. 사용자는 커넥터가 무슨 일을 하고 있는지 눈으로 확인하고, 탭을 옮겨 다니지 않고 그 자리에서 함께 작업할 수 있다.

Enterprise-managed auth(엔터프라이즈 관리형 인증)는 관리자가 자사 아이덴티티 제공자(IdP)를 통해 조직 전체에 MCP 커넥터를 프로비저닝할 수 있게 한다. 관리자가 커넥터를 한 번 승인해 두면 사용자는 기존 IdP 그룹을 통해 접근 권한을 물려받고, 첫 로그인 시점에 곧바로 연결된다. 최종 사용자 입장에서는 설정할 것이 전혀 없는 셈이다.

커넥터를 만드는 개발자를 위한 관측 기능(Observability)은 디렉터리에 게시된 커넥터에 대해, 여러 Claude 제품 표면에서 어떻게 동작하는지 보여주는 대시보드를 제공한다. 개발자는 이를 통해 채택 현황을 추적하고, 오류와 지연(latency)을 진단하고, 제품별로 사용량을 쪼개어 볼 수 있다.

MCP 터널(리서치 프리뷰)은 사설 네트워크 내부의 MCP 서버를 공개 인터넷에 노출하지 않고 Claude에 연결한다. 덕분에 팀은 인바운드 방화벽 규칙도, 공개 엔드포인트도, 오리진의 IP 허용 목록도 없이 사내 도구를 Claude로 가져올 수 있다.

2026-07-28의 상태 없는 코어, 표준화된 확장, 강화된 인증은 개발자가 더 많은 애플리케이션을 Claude로 가져오도록 돕고, 최종 사용자에게는 마찰이 적고 더 일관된 경험을 제공할 것이다. Anthropic은 앞으로도 커뮤니티와 함께 개방형 표준으로서의 MCP에 투자하고, 프로덕션 환경에서 MCP를 더 쉽고 효과적으로 쓸 수 있게 하는 Claude 기능에도 계속 투자할 예정이다.

시작하기

스펙과 SDK를 살펴보는 것으로 시작하면 된다. 관련 지원은 곧 Claude 제품 전반에 순차 적용된다. 자신의 MCP 서버를 Claude 커넥터 디렉터리에 제출할 계획이라면 여기에서 더 자세한 내용을 확인할 수 있다.
