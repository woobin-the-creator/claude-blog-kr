컴플라이언스 API 커버리지가 Claude Cowork와 Claude Code까지 확장된다

2026년 8월 11일 · 카테고리: 엔터프라이즈 AI(Enterprise AI), 제품 공지(Product announcements) · 제품: Claude Enterprise, Claude Code, Claude Cowork · 읽는 데 5분 원문: Compliance API coverage extends to Claude Cowork and Claude Code (한글 번역본)

Claude의 컴플라이언스 API(Compliance API)가 이제 데스크톱 앱·웹·모바일에 걸친 Cowork와, CLI 및 데스크톱 앱의 Claude Code까지 포괄한다. 이 커버리지는 Claude Enterprise 고객을 대상으로 베타로 제공된다. 컴플라이언스 팀과 보안 팀은 이미 Claude 채팅에 쓰고 있는 것과 동일한 컴플라이언스 API 인터페이스를 통해 두 제품의 세션 콘텐츠와 메타데이터를 가져올 수 있다.

새 엔드포인트는 추가(additive)되는 것이다. 지금 컴플라이언스 API로 이미 가져오고 있는 데이터에는 아무것도 달라지지 않는다.

보안·컴플라이언스 팀은 감사(audit)와 이디스커버리(eDiscovery)를 위해, 표면(surface)마다 별도의 로깅 인프라를 배포하지 않고도 조직 전반에서 Claude가 어떻게 쓰이는지 파악하기 위해 컴플라이언스 API에 의존한다. 커버리지가 Cowork와 Claude Code로 확장되면서 그 공백이 메워진다. 이제 그 세션들도 Claude 채팅과 나란히 나타난다.

작동 방식

새 세션 엔드포인트는 Cowork와 Claude Code 세션마다 서버에 호스팅된 통합 트랜스크립트(transcript)를 반환한다. 따라서 프롬프트, 응답, 도구 활동(tool activity)이 하나의 세션 레코드에 함께 담겨 돌아온다.

각 세션 레코드는 두 종류의 데이터를 담고 있다.

  • 세션 콘텐츠(Session content): 프롬프트와 응답, 도구 호출 콘텐츠(웹 및 MCP), 그리고 트랜스크립트 텍스트로 캡처된 스킬(skills)·아티팩트(artifacts) 콘텐츠.
  • 세션 메타데이터(Session metadata): 검증된 사용자 ID와 이메일 주소, 조직 ID, 세션 ID 및 메시지별 ID, 타임스탬프.

이번 베타에는 웹에서의 Claude Code, Claude Platform을 통해 접근하는 Claude Code, 그리고 Amazon Bedrock·Google Cloud의 Vertex AI·Microsoft Foundry에서 실행되는 세션은 포함되지 않는다.

이미 OpenTelemetry 데이터를 내보내고 있는 조직은 그대로 유지해도 된다. 컴플라이언스 API는 그것과 함께 동작할 수 있으며, 조직 쪽에 별도로 필요한 인프라는 없다.

시작하기

Cowork와 Claude Code에 대한 커버리지는 오늘부터 사용할 수 있고, 기존 컴플라이언스 액세스 키(Compliance Access Key)를 사용해 컴플라이언스 API에 포함되어 제공된다. 별도로 구축해야 하는 통합 작업은 없다. 조직에서 이미 활성화되어 있다면 새 세션 엔드포인트를 바로 쿼리하면 된다. 아직이라면 컴플라이언스 API 문서를 확인해 활성화하면 된다.
