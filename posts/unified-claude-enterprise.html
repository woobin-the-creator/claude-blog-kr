Enterprise에서 Claude Cowork와 채팅이 하나로

2026년 10월 23일 · 카테고리: Announcements · 제품: Claude Enterprise · 읽는 시간 2분 원문: Claude Cowork and chat come together for Enterprise (한글 번역본)
편집자 주: 2026년 10월 30일 이전에 작성된 이 글에서 Max를 언급한 부분은 현재의 Max 플랜과 Ultra 플랜을 모두 포함합니다.

채팅과 Cowork는 9월에 Pro·Max 플랜에서 먼저 하나로 합쳐졌습니다. 이제 같은 통합 Claude 경험이 Claude Enterprise 플랜에서도 정식 출시(GA)되었습니다.

이제 웹, 데스크톱, 모바일에서 채팅과 Cowork는 하나의 Claude이므로, 팀은 같은 대화 안에서 간단한 질문을 하거나 프로젝트 전체를 맡길 수 있습니다. 에이전트 작업(agentic work)은 Anthropic이 관리하는 클라우드 환경에서 실행되며, Claude Enterprise 관리자는 역할별로 접근 권한을 제어하고 새로운 효율 모드(Efficient mode)로 사용량을 관리할 수 있습니다.

모든 작업을 위한 하나의 Claude

팀원들은 이제 Claude와 일을 시작하기 전에 채팅과 Cowork 중 하나를 고를 필요가 없습니다. 대화는 채팅으로 시작되며, 간단한 질문에는 여전히 빠른 답이 돌아옵니다. 작업에 코드 실행이나 파일 작업이 필요하면 Claude가 클라우드에서 이어서 작업한 뒤 완성된 문서, 분석, 또는 발표 자료(deck)를 돌려줍니다. 작업이 클라우드에서 실행되기 때문에 노트북을 덮은 뒤에도 계속 진행되고, 웹·데스크톱·모바일 어디서든 이어서 볼 수 있습니다. 채팅, 프로젝트, 커넥터(connector), 스킬(skill), 플러그인(plugin)은 새 통합 경험으로 그대로 이어집니다.

여러 조직이 이미 팀 전반에서 통합 Claude 경험의 가치를 확인하고 있습니다.

보안 유지

조직에서 이미 Claude 채팅을 승인했다면, 이번 변화는 싱글 사인온(SSO)과 Compliance API를 포함해 이미 쓰고 있는 엔터프라이즈 제어 기능 위에 그대로 얹힙니다. Anthropic은 여전히 전송 중인 데이터와 저장된 데이터를 암호화하며, 기본적으로 데이터를 모델 학습에 사용하지 않습니다.

Claude는 에이전트 작업을 클라우드 세션에서 수행합니다. 각 세션은 독립된 가상 머신(VM)에서 실행되며, Claude Enterprise에서는 네트워크 외부 송신(egress)이 기본적으로 꺼져 있고 커넥터 자격 증명(credential)은 샌드박스 밖에 보관됩니다. 이 작업이 Anthropic이 관리하는 하나의 환경에서 실행되기 때문에 보안 팀은 이를 중앙에서 파악하고 제어할 수 있습니다. 전체 아키텍처는 Anthropic Trust Center의 보안 모범 사례 가이드에서 다룹니다.

비용 관리

Claude Enterprise 가격 정책은 계속 사용량 기반입니다. 최신 Claude 모델은 이전 모델보다 효율적입니다. 사용량 기준으로 과금할 때 일반적인 워크로드에서 Claude Opus 5.5는 Claude Opus 5보다 실행 비용이 40% 적게 들고, Claude Sonnet 5.5는 대부분의 작업에서 Claude Sonnet 5보다 최대 30% 적게 듭니다.

작업에 따라 에이전트 작업은 간단한 채팅보다 토큰을 더 많이 쓸 수 있습니다. Claude Enterprise 관리자에게는 이 사용량을 관리할 수 있는 네 가지 제어 수단이 있습니다. 효율 모드(Efficient mode)는 통합 Claude 경험을 Sonnet과 Haiku 모델로 유지하는 새 설정입니다. 모델 사용 권한(model entitlements)은 역할마다 어떤 모델을 쓸 수 있는지 정합니다. 지출 한도(spend limit)는 조직, 그룹, 구성원 수준에서 적용되며, 그룹 공동 예산(pooled group budgets)은 그룹이 함께 꺼내 쓸 하나의 공유 월간 예산을 부여합니다.

시작하기

통합 Claude 경험은 오늘부터 Claude Enterprise 플랜에서 정식으로 사용할 수 있습니다. 관리자는 조직 설정(Organization settings)에서 배포를 관리할 수 있습니다. Claude Code에 데이터 무보존(zero data retention)을 쓰거나, HIPAA 대응 구성을 쓰거나, 고객 관리 암호화 키(customer-managed encryption keys)를 쓰는 조직은 현재 구성을 그대로 유지합니다.
