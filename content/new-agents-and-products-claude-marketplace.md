  <h1>Claude Marketplace에 보안·생산성·크리에이티브 작업을 위한 새 에이전트와 제품 추가</h1>

<p><a href="https://claude.com/marketplace">Claude Marketplace</a>에 새로운 에이전트와 제품을 추가했습니다. Claude Marketplace는 팀이 Claude를 더 잘 활용하도록 돕는 파트너 도구와 서비스를 찾는 곳입니다. 이번에 추가된 항목은 보안, 개발자 인프라, 크리에이티브, 생산성 분야를 아우릅니다.</p>

<p>자격을 갖춘 엔터프라이즈 고객은 Anthropic과 약정한 지출(committed spend)의 일부를 이 솔루션들에 적용할 수 있습니다. 덕분에 새 제품을 구매하든, 이미 쓰고 있는 플랫폼을 확대하든, 하나의 약정으로 Claude와 파트너 제품을 함께 이용할 수 있습니다.</p>

<p>이제 마켓플레이스에는 25개가 넘는 파트너 에이전트와 제품이 있습니다. 새로 추가된 항목과 각각으로 팀이 할 수 있는 일을 소개합니다.</p>

<h2>코드와 시스템을 보호하는 제품과 에이전트</h2>

<p><a href="https://claude.com/marketplace/agents-products/chainguard">Chainguard</a>: Chainguard Harness는 격리된 microVM에서 소스로부터 애플리케이션을 빌드하고, 실행 중인 앱을 탐색해 악용 가능한 취약점을 찾아냅니다. 재현 가능한 취약점에 대해 맞춤형 해결(remediation) 권장 사항을 제공해, Claude가 찾아낸 문제를 팀이 고칠 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/checkmarx">Checkmarx</a>: Checkmarx One은 규칙 기반 분석과 AI 추론을 결합해 코드 속 취약점을 찾습니다. 팀이 발견 사항의 우선순위를 정하고 코드가 출시되기 전에 고칠 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/cyera">Cyera</a>: Cyera Agent Guardian은 Claude 배포 현황을 목록화하고, Claude가 실행되기 전에 권한을 관리하며, 프롬프트·파일·도구 호출(tool call)에 정책을 적용합니다. 레드팀(red teaming)을 통해 팀이 이러한 통제를 시험해 볼 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/rubrik">Rubrik</a>: Rubrik Code Guardian은 Anthropic의 프론티어 AI 모델을 사용해 GitHub 또는 Azure DevOps 리포지토리의 안전한 사본을 검토하고, 여러 단계로 이어지는 공격 경로를 찾아냅니다. 보안 팀과 엔지니어링 팀이 이슈를 심각도별로 순위 매기고, 확인된 치명적 이슈를 추적 가능한 티켓으로 만들 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/tanium">Tanium</a>: Tanium Cloud는 팀이 엔드포인트 전반을 실시간으로 파악하고 통제할 수 있게 해 줍니다. IT 팀과 보안 팀이 취약점, 잘못된 구성(misconfiguration), 누락된 패치를 찾아 고칠 수 있게 돕습니다.</p>

<h2>엔지니어링 팀을 위한 개발 인프라</h2>

<p><a href="https://claude.com/marketplace/agents-products/datadog-agent-observability">Datadog</a>: Datadog Agent Observability는 도구와 서비스를 거치는 에이전트 실행 과정을 추적(trace)합니다. 프로덕션 환경의 패턴을 드러내고 수정 방안을 권장해, 팀이 에이전트의 품질·성능·비용 효율을 개선할 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/netlify">Netlify</a>: Netlify Enterprise는 앱, 사이트, 에이전트를 글로벌 엣지 네트워크에 배포하며, 변경할 때마다 미리보기 URL을 제공합니다. 설정할 인프라 없이 팀이 Claude로 만든 것을 프로토타입에서 프로덕션까지 가져갈 수 있게 돕고, SSO, 역할 기반 접근 제어(role-based access), 감사 로그(audit log)를 포함합니다.</p>

<h2>마케팅과 크리에이티브 작업을 위한 도구</h2>

<p><a href="https://claude.com/marketplace/agents-products/airops">AirOps</a>: AirOps는 AI 검색 전략, 콘텐츠, 멀티채널 실행을 위한 에이전틱 플랫폼을 제공합니다. 마케팅 팀이 AI 검색에서의 브랜드 성과를 분석하고, 그 결과를 파이프라인 및 매출과 연결할 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/runway">Runway</a>: Runway는 영상, 이미지, 오디오를 생성하고 편집합니다. 크리에이티브 팀과 마케팅 팀이 브리프를 완성된 에셋으로 바꾸고, 자연어로 영상을 편집할 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/webflow">Webflow</a>: Webflow는 웹사이트를 구축·관리·최적화하는 내장 도구를 제공합니다. 통제와 거버넌스가 기본으로 갖춰진 상태에서 마케터, 디자이너, 개발자, 그리고 에이전트가 변경 작업을 할 수 있게 돕습니다.</p>

<h2>모든 팀을 위한 생산성 앱</h2>

<p><a href="https://claude.com/marketplace/agents-products/asana">Asana</a>: Asana AI Teammates는 Asana Work Graph의 컨텍스트를 활용하는 사전 구축 에이전트로, 각자 고유한 ID, 범위가 지정된 권한(scoped permissions), 감사 기록(audit trail)을 갖습니다. 판단이 필요한 결정은 담당자에게 넘기면서, 팀이 여러 단계로 이뤄진 작업을 처리할 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/glean">Glean</a>: Glean은 여러 시스템에 흩어진 회사 지식과 워크플로를 연결합니다. 직원들이 답을 찾고, 연결된 앱들을 넘나들며 여러 단계의 작업을 완료할 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/monday">monday</a>: monday 에이전트는 프로젝트, 보드, 문서, 회의 안에서 일하며, 각 항목의 담당자와 마감일을 컨텍스트로 활용합니다. PMO, IT, 마케팅, 재무, 운영 팀이 AI가 무엇에 접근하고, 무엇을 승인하고, 얼마를 지출할 수 있는지 통제할 수 있게 돕습니다.</p>

<p><a href="https://claude.com/marketplace/agents-products/zoom">Zoom</a>: Zoom Agentic Search는 최신 회의 요약, 업무 대화, 문서, 연결된 서드파티 소스를 활용해 Claude 안에서 질문에 답합니다. 팀은 원본 녹취록을 분석하거나 여러 도구를 연쇄로 엮지 않고도 권한을 반영한(permission-aware) 결과를 얻습니다.</p>
